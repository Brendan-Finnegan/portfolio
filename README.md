# Brendan Finnegan Portfolio

A personal portfolio website built with plain HTML and CSS. There is no build step or package installation required.

## Pages

- `index.html` is the home page.
- `writing.html` is the writing index.

Both pages share styles from `styles.css`. The home page uses `images/headshot.jpg`, and the site loads the Schibsted Grotesk font from Google Fonts.

## Preview

Open `index.html` in a browser, or serve the project locally from its root directory:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
